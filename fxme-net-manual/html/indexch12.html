12.1  Ports

Port

Protocol

Use

54320

UDP

Discovery: answers the plugin’s Find. Optional.

54321

UDP

Audio: requests and replies of all sessions, and telemetry.

54322

TCP

Control: the plugin lists, parameters, state, and fxmenet-top.

All three can be changed with the server’s options (chapter 3). The client opens connections to the server; the server only needs these three ports open to the client.

12.2  Bandwidth

Audio travels as 32-bit floating-point samples, uncompressed, in both directions: about 2.8 Mbit/s for a stereo track at 44.1 kHz, 3.1 Mbit/s at 48 kHz, and the more for more channels. In the first stress tests, 24 stereo tracks used about 71 Mbit/s each way and 32 tracks used 95 Mbit/s each way. A gigabit connection carries several hundred tracks of this kind in theory; in practice, the server’s CPU and the quality of the network limit the number of tracks first.

Only the channels that the routing uses are sent (chapter 6).

12.3  Security

The traffic is not encrypted or authenticated. A token in each session keeps stray packets out, but anyone on the network can talk to the server. Use FxmeNet on a network you trust, and keep the ports closed on the internet.
