13  Glossary

Aux bus

A plugin input or output beyond its main ones, such as a sidechain.

Block

A group of N samples sent to the server and returned.

Budget (D)

The number of blocks of time a reply has to come back.

Chain

The plugins of a session, in processing order.

Client

The FxmeNet plugin in the DAW.

Concealed block

A block whose reply was late, replaced by a short fade to silence and back.

Control channel

The TCP connection that carries plugin lists, parameters and state.

Discovery

The broadcast that lets Find locate servers.

Mirror

The local copy of a server plugin that shows its editor and never processes audio.

Monitor

A connection that watches a server without a session (fxmenet-top).

Pin

The place where a connection joins a plugin’s input or output in the routing view.

Pool

The 256 automation parameters of an FxmeNet instance.

Server

fxmenet-server.

Session

One FxmeNet instance connected to the server.

Telemetry

The values (meters, spectra) a plugin made for FxmeNet sends from the server to its editor on the client.

Tier

T0, T1 or T2: how a plugin can be shown on the client (chapter 8).
