8  Tiers: editors and meters

Every plugin in the server’s list carries a tag, T0, T1 or T2. It says what you can have on the client for that plugin.

Tier

What you get

T2

The plugin’s own editor on the client, with its meters, spectra and other displays showing the server’s real signal. The plugin is made for FxmeNet (chapter 9) and installed in the same version on the client.

T1

The plugin’s own editor on the client, kept in step with the server’s copy. Meters and analysers that read the audio inside the plugin stay empty, since the audio is not on the client.

T0

Generic controls: a slider per parameter. Used when the plugin is not installed on the client, or is another version.

8.1  How the plugin decides

The plugin scans the VST3 folders of the computer that runs the DAW. A server plugin matches a local one when the identifier, the name and the vendor are the same. The version then decides:

  • the same version, and the server says the plugin is made for FxmeNet: tier T2;
  • the same version otherwise: tier T1;
  • another version, or no local copy: tier T0.

When both computers run the same operating system, the plugin also compares the binary files. A difference (another build of the same version) is shown on hover but does not stop the plugin from being used. Hover over a row of the list to see the reason for its tier.

The FxmeNet plugin itself is never listed, and neither are instruments.

8.2  What the local copy does

For tiers T1 and T2, the plugin creates a local copy of the server’s plugin when you first open its editor. This mirror never processes audio; it only shows the editor. Your changes go to the server, and the server’s state comes back to the mirror. For a plugin made for FxmeNet, whatever the plugin changes outside its parameters (a preset, a loaded file) is copied to the server in full.

Note.  Install the same plugin versions on both machines. A tier T1 or T2 editor on a different version is a source of surprises, so FxmeNet does not use it; the plugin shows as tier T0.

8.3  Keeping the plugin list up to date

If you install a plugin on the client while the DAW runs, use Rescan in the Settings tab, and the tags update. If your plugins live in a folder that is not standard, add it with Folders….

8.4  Plugins made for FxmeNet

These FX-Mechanics plugins are made for FxmeNet (tier T2 when the same version is installed on both computers). Install them on the server, and on the computer that runs the DAW to have their editors and meters.
