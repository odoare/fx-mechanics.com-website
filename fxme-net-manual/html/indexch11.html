11.1  Files

File

Content

FX-Mechanics/ fxmenet-server-plugins.xml

The server’s plugin cache.

FX-Mechanics/ fxmenet-server-settings.json

The folders and the default-folders switch set with fxmenet-top.

FX-Mechanics/FxmeNet.settings

Client: the last server, the hover-help switch, the extra plugin folders (machine-wide).

FX-Mechanics/ fxmenet-client-plugins.xml

Client: the cache of the local plugin scan.

FX-Mechanics/ fxmenet-client-events.log

Client: the transport events log, when enabled.

The FX-Mechanics folder is in the user’s application-data folder (on Linux, ~/.config; on Windows, %APPDATA%; on macOS, ~/Library/Application Support). [TODO: verify these locations on each system]

11.3  Limits

  • 256 automation parameters per FxmeNet instance.
  • 1 to 64 channels in and out of each FxmeNet instance (stereo by default).
  • Block sizes from 32 to 1024 samples; a network budget of 1 to 8 blocks.
  • Plugins: VST3 effects on the server.

11.4  More documentation

The project’s doc folder holds the technical documents: architecture.md (how the code is built), protocol.md (the wire protocol, for anyone writing another client or tool), routing.md (the design of the routing) and Tests/stress-tests.md (the measurements of chapter 7 in full).
